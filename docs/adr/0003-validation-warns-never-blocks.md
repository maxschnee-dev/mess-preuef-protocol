# 0003 – Validation warns, never blocks

Status: accepted (2026-10-17)

Messwerte are checked live against Grenzwerte (NIN SN 411000 values, kept in one data table). A Verstoss colours the field and shows the required boundary (e.g. "≥ 255 A") – no NIN reference text. Saving and PDF export are never blocked, because real defects must be recordable. Limits must be verified by a qualified person against the current NIN before production use.
