# 0002 – PDF generated in the app, not via print CSS

Status: accepted (2026-10-17)

The finished Protokoll is exported as a real PDF built in the browser (reproducing the VSEI 133-D layout, without association logos) with pdfmake, rather than relying on "Print → Save as PDF". This gives a consistent file on phones/tablets, where browser printing is unreliable, and lets us embed the finger-drawn signatures.
